# 第二轮：句子、段落与术语的语言精读

日期：2026-11-09。目标是读懂作者具体怎样表达，而不只整理研究逻辑或收集句型。沿用前一轮的全文理解，再返回代表段落检查措辞、语法、指代、信息顺序和证据强度。

## 本轮材料与覆盖

- ColdMap：从引言、设计、结果、开销和结论选12处句段，逐项分析。
- OAZA/OAZA-GC：从动机、方法、算法说明、开销、结果选12处句段，逐项分析。
- JSA μScope：3处；JSA ADAPT：1处；ATC ZNS：1处，作为语言对照。
- 合计29个来源锚点。两篇主文原本已全文读完；本轮是代表句段的语言精读，**不是声称对这五篇每句话都完成了语言审校**。

每处分析先定位原文，再解释句子在段落中的任务、用词为什么重要，以及借用时需要满足什么条件。论文存在的夸张、歧义或不自然英文也保留，不因已经发表就照搬。

## 阅读产物

1. [逐句与段落精读](逐句与段落精读.md)：24处主文句段，加5处跨论文对照；原文短摘、上下文功能和语言判断相互对应。
2. [术语与语言细节](术语与语言细节.md)：候选术语表、动词语义、时态/语态、冠词/指代、数值比较和本课题的表达边界。
3. `source-anchors.json`：29个原文锚点的PDF页码、来源文件哈希及规范化匹配位置。哈希与文本匹配验证出处，不能代替语义判断。
4. `verification.json`：锚点、链接和论文工程身份核验结果。

短摘只为定位和评论，完整上下文请回原文阅读。断行和PDF排版连字符在匹配时做规范化；正文中注明是完整句还是片段。来源为已有本地PDF，未重新上传论文到外部服务。本文中的原创英语练习均为教学示例，不是论文正文、作者原话或本项目实验结果。

## 后续写作怎样使用

先确定要表达的事实和证据，再选动词、限定语和信息顺序；保留术语的一致性。不会把原句替换几个名词后直接放进论文，也不会为“更像论文”增加没有证据的优势形容词。

本轮只新增语言阅读资料，并更新索引。英文稿、参考文献库、模板、基线代码和实验数据均不修改；不涉及编译或实验测试。
